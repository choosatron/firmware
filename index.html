Updating a Choosatron

You should not need anything on this page. Connect to the device's Wi-Fi, open its web interface, and go to Firmware — it checks here by itself and installs with one press.

Stories, playlists and Wi-Fi settings are kept across an update. If a new version does not start correctly, the device returns to the previous one on its own.

Installing over USB

The easy way: the Choosatron flasher. It reinstalls or recovers a Choosatron from Chrome or Edge on a computer, with nothing to install, and offers every release below.

For a device that cannot be reached over Wi-Fi, or one that needs recovering, each release includes a recovery image, choosatron-factory.bin: the bootloader, partition table and application in one file, written at the start of the flash. To write it by hand instead:

esptool.py --chip esp32s3 write_flash 0x0 choosatron-factory.bin

The recovery image keeps the stories and playlists. It resets the settings, Wi-Fi included, to how they were when the device was new, so afterwards the device comes up as its own open network again.

For tooling: the machine-readable index is manifest.json. Point update checks at that, served from this Pages site — GitHub release-asset URLs are served without CORS headers and cannot be read by a browser.
